# 山河棋局

白色平面战略模拟游戏，真实矢量海岸、水系与高程山体，包含三国与二战亚洲两个年代地图。

## 启动

在线游玩：[山河棋局](https://dns0129.github.io/2D_slg_game/)。GitHub Pages 从 `main` 分支根目录发布，后续提交会自动更新站点。

### macOS

双击仓库根目录的 `start-game.command`，用系统为 HTML 文件设置的默认浏览器打开游戏。也可以在终端中运行：

```sh
./start-game.command
```

如果下载的 ZIP 未保留执行权限，在游戏目录运行一次 `chmod +x start-game.command`。启动脚本会定位自身所在目录，支持中文和空格路径，不需要安装 Python。

### Windows

在游戏目录打开 PowerShell 或 Windows Terminal，运行：

```powershell
.\start-game.cmd
```

也可以双击 `start-game.cmd`。它会用系统为 HTML 文件设置的默认浏览器打开游戏，不需要安装 Python。如果系统把 HTML 文件关联到了编辑器，请先把 `.html` 的默认应用设置为浏览器。

### 本地 HTTP 服务（可选）

也可直接用浏览器打开 `index.html`，或在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 <http://127.0.0.1:8765/>。地图与山体资源在本地，不依赖在线地图服务。

本地文件、HTTP 服务和在线站点使用各自的浏览器存储；切换启动方式或浏览器时，原有存档不会自动迁移。

## 地图与玩法

- 地图铺满游戏窗口。左上悬浮政治、经济和军事概览；右上显示当前年月；左下小地图可点击或拖动定位，视野框随主地图移动。
- 三国默认放大魏、蜀、吴核心战区以铺满视野，初始显示郡界、主要历史城市及更细的水系，高分辨率山体直接启用。默认视角随窗口比例调整；“全域”和小地图仍可查看辽东、交州等边缘疆域。
- 地块情报在右下悬浮展开，可关闭；概览面板也可收起。各国默认以淡色填充，保留白色山体与水系细节。
- 最外层是国家概览，合并当前同一国家控制的地块，只显示国家轮廓和名称；点击国家可查看其州省及辖区。
- 放大后显示州省和省内地块。最大放大限于一个省级行政区（三国为州）的完整范围，滚轮、按钮、地名搜索、地块定位和存档恢复均遵守此限制。仍能查看省内郡县、城市标签及地块情报。
- 滚轮和按钮使用连续缓动缩放；连续操作从当前镜头接续，滚轮保留鼠标处的地理位置。文字、州省边界、省内边界、城市及兵力信息随缩放渐显渐隐，山体和水系也渐变展开。国家悬停只高亮填色和外轮廓，所有地图边界采用实线。
- 平移和缩放时使用本地缓存的 Canvas 图层，停止后恢复完整矢量细节。滚轮输入和拖动共用每帧一次的调度；文字重新排版降低频率，渐变仍逐帧更新。移动期间暂时停用悬浮面板的背景模糊，避免反复采样整个地图。缓存像素数有上限，并在大幅放大时更新清晰度；不支持 Canvas Path2D 时自动沿用 SVG。
- 滚轮以鼠标位置为中心缩放；可从领土上拖动浏览。支持地名搜索、选区定位、亚洲全图、手动层级和势力视图。
- 点击己方地块征兵、发展；选择相邻地块行军或进攻。⛵ 是游戏海路。
- 每回合推进一个月，结算 AI 与收入。政治概览显示当前战区交战国家；进攻未交战国家时，按钮显示“宣战并进攻”。缩放不改变兵力和地块，历史行政底图固定在剧本起始日期。
- 中国省内战略地块以当地代表城市或聚落命名，例如江苏：南京、徐州、苏州、盐城；浙江：杭州、宁波、金华、温州。三国保持当时州郡名称，二战保留北平、迪化等历史名称。城市名表示代表地点，不能解释为该城市的历史市界。
- v3 进度保存在本机浏览器；旧示意地图 v1 存档保留。

## 历史精度

三国使用历史州郡底本，二战固定 1941-12-06，保留民国历史省名、东京府、朝鲜十三道、殖民行政结构等。每个地块可查看底本日期、来源和复原限制。

**中国省内当前仍有战略分区，不是已核实的 1941 县界或督察区界。部分古代郡域和亚洲地区细界仍需历史精校。** 详细图源、许可、已核对沿革和未完成项目见 [maps/SOURCES.md](maps/SOURCES.md)。

## 验证与扩展

`scripts/build_atlas.py` 构建矢量地图、层级、真实邻接和分辨率不同的山体图层。新剧本提供独立年代区划数据与 `meta`，由游戏自动注册。

`scripts/name_strategic_regions.py` 为战略地块设置代表地名，并检查城市坐标位于对应地块内；可单独运行，完整构建也会调用。它保留地块 ID 和边界，兼容原有进度。

`scripts/verify_atlas.cjs` 进行 DOM 逻辑检查，并导出实际游戏 SVG 为 PNG，结果在 `previews/historical-atlas-v3/output/`。这些检查不等同于真实浏览器的点击、滚轮、触屏体验验收。

`scripts/verify_map_levels.cjs` 专项检查国家轮廓、层级切换、不同省份的最大放大、搜索定位、宽屏与旧存档恢复，并导出国家概览和省级缩放上限的实际地图图像。

`scripts/verify_zoom_motion.cjs` 使用可控逐帧时钟检查动画中间帧、连续输入、鼠标锚点、图层渐变、拖拽中断、缩放范围和存档保留。此检查验证逻辑，不代表真实浏览器动画观感验收。

`scripts/verify_motion_performance.cjs` 比较同一组 176 帧动画的逻辑开销，并用原生 Skia 检查缓存绘制、连续滚轮合并、平移结束和实际地图画面。结果记录在 `motion-performance-checks.json`，不是浏览器 FPS 实测。

国家轮廓使用本地打包的 polygon-clipping 0.15.7 合并矢量多边形，按控制权变化更新；无需访问 CDN。其 MIT 许可与归属保存在 `vendor/polygon-clipping.LICENSE.md`。缺少省级历史细界的地区采用普通省级区域大小作为放大限度，不凭空增加省界。
