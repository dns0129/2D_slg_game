# 1939–1945 全球县级行政区划与实际控制数据库

六个时间断面，全球约 5 万个县级单元。每个县记录：所属政治单元（国家 / 殖民地 / 保护国）、法理宗主、
当日的实际控制者、控制方式、所属阵营、估计人口。附六张可交互地图。

| 断面 | 事件 |
|---|---|
| 1939-09-01 | 德国入侵波兰，第二次世界大战在欧洲爆发 |
| 1940-07-01 | 法国停战后，德国控制西欧 |
| 1941-12-07 | 珍珠港事件当日，德军止步莫斯科城下 |
| 1942-11-01 | 轴心国扩张的最大范围（阿拉曼、斯大林格勒之前） |
| 1944-06-06 | 诺曼底登陆日 |
| 1945-09-02 | 日本签署投降书，战争结束 |

## 文件

```
db/ww2_counties_1939_1945.sqlite   数据库（下文“表结构”）
ww2/maps/index.html                交互地图（默认 1942-11-01，可切换六个断面）
ww2/maps/<日期>.html               六个断面各一页，打开即为该日
ww2/maps/data/                     地图数据（几何为二进制，属性为 JSON，可直接导入其他项目）
curated/ww2_region_control.csv     人工整理的分区控制规则（按日期、按现代一级/二级政区或县名）
curated/control_events.csv         整个政治单元的控制事件（与 1900–2000 数据库共用）
scripts/ww2_*.py                   全部构建脚本；build_all.sh 末尾为本部分的完整流程
```

本地查看地图：在 `world-history-data/ww2/maps/` 下运行 `python3 -m http.server`，浏览器打开
`http://localhost:8000/`（直接双击 HTML 文件时浏览器会拦截数据读取）。

## “县”的定义

全球没有统一的 1939–1945 年县级界线数据，因此分两类：

1. **当时的历史界线**（`basis` 不是 `modern_proxy`，约 3,600 个）
   - 美国：Newberry 图书馆《美国县界历史地图集》，每个县带起止日期，按断面日期取当日有效的县（`historical_dated`）。
   - 台湾：中研院 1930 年州厅—郡市界（`historical_1930`）。
   - 缅甸：1931 年人口普查的县（district）（`historical_1931`）。
   - 朝鲜：国史编纂委员会 1914–1926 年面事务所等地点，按郡/府归属在 13 道界内做 Voronoi 剖分重建郡界
     （`reconstructed_1914_1926`；郡界为近似，道界为描绘原图）。
2. **现代界线代用**（`modern_proxy`，约 4.6 万个）：其余国家使用 geoBoundaries 的现代政区，
   每国自动选取中位面积最接近典型县（约 1,500 km²）的一级，见 `county_levels` 表；之后按当日的
   CShapes 国界切分。中国的县还对上了国家统计局中文县名（拼音匹配，约 2,500 个）。

3. **整块殖民地**（`historical_unit`）：geoBoundaries 没有数据的瓜德罗普、新喀里多尼亚、法属波利尼西亚，用 CShapes
   的整块殖民地轮廓当作一个单元。

CShapes 没有画出的小岛屿属地（南洋群岛、关岛、科威特、巴林、格陵兰、背风/向风群岛、塞舌尔、多德卡尼斯群岛、千岛群岛等）
在 `ww2_snapshots.py` 的 `ISLAND_UNITS` 中直接指定所属政治单元（`unit_id` 为负数，地图上没有国界线），
人口按约 1940 年的近似总数（取整）分摊。

县的上级尽量用当时的政区（`hist_parent`）：中华民国各省（ENP-China）、满洲国各省、关东州、蒙疆、
法属印度支那各省、荷属东印度、1939 年菲律宾省、朝鲜 13 道、印度土邦（1931）、美国各州等。
伪满洲国、关东州的县另记 `defacto_parent`（实际管辖的伪政权省份）。

## 实际控制的判定（优先级从低到高）

1. CShapes 2.0 在该日期的国界与宗主（殖民地归宗主国）。
2. `control_events.csv`：整个政治单元的被占领 / 傀儡政权等事件（如丹麦、挪威、荷兰、比利时、希腊）。
3. 东亚历史图层：满洲国（1945-09-02 改为苏军）、蒙疆、1942 年日占区（1939、1940、1944 沿用，
   标为近似；1945-09-02 标为“待受降”）、中共抗日根据地（1941、1942）、1941 年割让给泰国的柬埔寨、老挝领土。
4. `ww2_region_control.csv` 的分区规则（按文件顺序，后者覆盖前者），共约 100 条。`field` 可按现代一级 / 二级政区、
   县名或当日的政治单元名（`unit`）匹配。例如：法属赤道非洲、喀麦隆、新喀里多尼亚、法属波利尼西亚（1941、1942 归自由法国），
   叙利亚、黎巴嫩（1941 年起自由法国），马达加斯加（1942 英军），法属印度支那（1941–1944 日军进驻、1945 待受降），
   法国占领区 / 维希区 / 阿尔萨斯—摩泽尔，东线各州在各断面的归属（含“前线争夺”），芬兰占领的东卡累利阿，
   南斯拉夫的瓜分，北特兰西瓦尼亚，意大利 1944 年战线，伊朗占领区，太平洋岛屿，德奥占领区（1945）。

一个县在当日被国界切开时会拆成多块（`piece_id` 为 `county_id@单元号`，占比 < 3% 的碎块并入主块）。

阵营 `bloc`：`allied`（同盟国一方）、`axis`（轴心国及其附庸、占领区）、`neutral`（中立国及尚未参战的国家，
维希法国记为中立）、`contested`（前线争夺）。阵营按断面划分并作了简化：英法及其殖民地、中华民国自 1939-09-01
起即计入同盟国一方（英法于 9 月 3 日宣战）；苏联、美国自 1941-12-07 断面起计入同盟国；匈、罗、保、芬在
1941–1944 断面计入轴心国，罗、保在 1945 断面计入同盟国；拉美等国按对轴心国宣战的时间逐步计入。

`control_confidence = approximate` 表示该县的控制按整区分配或沿用临近年份的范围，
真实前线可能从县内穿过（地图上为斜线）。

## 人口

县人口为估计值：用 GHS-POP 1975 年人口格网（30″）算出每县在本国内的人口占比，乘以该政治单元在当年的人口
（来自本仓库 1900–2000 数据库的 `unit_year` 表；美国按各州人口普查数校准）。它反映的是 1975 年的人口分布格局，
不是当时的县级普查数，县与县的比较只宜作参考。

## 主要局限

- 欧洲、苏联、中国内地、日本本土、拉美、非洲的县界都是现代界线代用，不是 1939–1945 年的真实县界；
  旧县名、已撤并的县不会出现（中国县名为今名）。
- 东线、意大利、缅甸、中国战场等前线以整个州 / 省为单位分配，`front_line` 只表示“前线经过此区域”。
- 中国日占区在 1939、1940、1944 年沿用 1942 年的范围（1944 年豫湘桂战役新占地区未单列）。
- 朝鲜郡界为点位重建；1941 年以后的郡界调整未体现。

## 表结构（SQLite）

| 表 | 内容 |
|---|---|
| `meta` | 说明、坐标系、构建时间 |
| `sources` | 数据来源、引用、许可证 |
| `snapshots` | 六个断面及各阵营人口 |
| `counties` | 县：名称、中文名、类别、来源层级、历史上级、现代政区、面积、标注点、几何（GeoJSON，简化 0.006°，坐标保留 3 位小数） |
| `split_pieces` | 被国界切开的县的各块几何 |
| `county_snapshot` | 每个断面的每一块县：所属政治单元 `unit_id`、控制记录 `control_id`、面积、估计人口 |
| `unit_snapshot` | 每个断面的政治单元：名称、地位（独立 / 殖民地 / 保护国 / 委任统治）、法理宗主、局部控制事件 |
| `controls` | 控制记录：实际控制者、细节、控制方式、判定来源、可信度、阵营 |
| `pop_methods` | 人口估计方法说明 |
| `county_snapshot_full`（视图） | 上面四张表连起来的宽表，一行一块县一个断面，包含全部属性，查询时直接用它 |
| `control_rules` | 分区控制规则原文（`row` 为 CSV 行号，与 `control_source = rule:<行号>` 对应） |
| `control_events` | 整单元控制事件 |
| `county_levels` | 每国代用政区所选的层级与中位面积 |

```sql
-- 1942-11-01 日本实际控制的县，按估计人口排序
SELECT c.name_zh, c.name, s.unit_name_zh, s.population_est
FROM county_snapshot_full s JOIN counties c USING (county_id)
WHERE s.snapshot = '1942-11-01' AND s.controller_gwcode = 740
ORDER BY s.population_est DESC LIMIT 20;

-- 某县在六个断面的归属变化（以基辅为例）
SELECT snapshot, controller_name_zh, control_type, bloc
FROM county_snapshot_full
WHERE county_id = (SELECT county_id FROM counties WHERE name = 'Kyiv' AND iso3_modern = 'UKR' LIMIT 1)
ORDER BY snapshot;

-- 各断面各阵营的估计人口
SELECT snapshot, bloc, SUM(population_est) FROM county_snapshot_full GROUP BY snapshot, bloc;
```

## 地图数据格式（`ww2/maps/data/`）

- `geo.bin`：所有断面用到的县块几何。逐个要素为 varint 序列：多边形数 → 每个多边形的环数 → 每个环的点数，
  后接 zigzag 编码的坐标差分（单位 1/1000 度，差分在同一要素内连续累计）。解码函数见 `index.html` 的 `decodeGeo`。
- `geo-units.bin`：CShapes 政治单元边界（同一编码）。
- `counties.json`：县的静态属性（列式存储：每列为 `lut` 去重表 + `idx` 下标）。
- `snap-<日期>.json`：该断面出现的要素下标、阵营、可信度、估计人口和控制属性。
- `terrain.png`：Web 墨卡托地形晕渲（透明度表示阴影）；`hydro.json`：主要河流与湖泊。
